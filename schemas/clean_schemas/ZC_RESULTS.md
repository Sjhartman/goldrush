# ZC_RESULTS

**Source:** https://datahandbook.epic.com/ClarityDictionary/Details?tblName=ZC_RESULTS

## Description

This table holds information about the category values corresponding to which result notifications a provider on a patient's care team wishes to receive. In Chronicles, this is stored in item EPT 80111. Before the Summer 2009 release, this was stored in item EPT 20610.
