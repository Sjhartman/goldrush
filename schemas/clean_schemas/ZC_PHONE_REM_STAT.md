# ZC_PHONE_REM_STAT

**Source:** https://datahandbook.epic.com/ClarityDictionary/Details?tblName=ZC_PHONE_REM_STAT

## Description

This is the status returned from an automated appointment reminder system.  Typically values for this are confirmed, cancelled, busy, etc...  This item is set by batch templates 91 and 96.
