# ZC_OR_STAFF_TYP_MAP

**Source:** https://datahandbook.epic.com/ClarityDictionary/Details?tblName=ZC_OR_STAFF_TYP_MAP

## Description

This table contains the category information for the staff type mapping associated with a staff member on a procedural case. The mapping is defined in the resource type record for the staff type.
