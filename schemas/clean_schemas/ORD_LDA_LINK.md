# ORD_LDA_LINK

**Source:** https://datahandbook.epic.com/ClarityDictionary/Details?tblName=ORD_LDA_LINK

## Description

Links between Orders (ORD) and LDAs.

## Columns

| Column | Type | Description |
| --- | --- | --- |
| ORDER_ID | NUMERIC (18,0) | The order ID KB SQL Table: CURRENT_LDA_LINK KB SQL Column: ORDER_ID |
| LINE | INTEGER | The chronicles item line. This does not actually have a KB SQL column. Extracted from LINE_COUNT |
| LDA_ID | VARCHAR (18) | The ID of the currently linked Line/Drain/Airway (LDA) KB SQL Table: CURRENT_LDA_LINK KB SQL Column: LDA_ID |
| LDA_PORT_C | INTEGER |  |
| LDA_INST_LINKED_TM | DATETIME (Local) | The instant when the current line linkage occurred. |
| LDA_COMMENT | VARCHAR (254) | A comment for the current Line/Drain/Airway (LDA) link. KB SQL Table: CURRENT_LDA_LINK KB SQL Column: LDA_COMMENT |
| LDA_INST_RECORD_TM | DATETIME (Local) | The instant that the current linkage was recorded. KB SQL Table: CURRENT_LDA_LINK KB SQL Column: LDA_INST_RECORDED |
| LDA_USER_ID | VARCHAR (18) | The user that recorded the current Line/Drain/Airway (LDA) link. KB SQL Table: CURRENT_LDA_LINK KB SQL Column: LDA_USER_ID |
| LDA_EDITED | INTEGER | Points to a line in the audit trail if the LDA linked to the order is edited. |
| CM_PHY_OWNER_ID | VARCHAR (25) | ID of the physical deployment owner for this record.  Physical owners will be where the data is hosted, either on the cross-over server or the owner deployment. |
| CM_LOG_OWNER_ID | VARCHAR (25) | ID of the logical deployment owner for this record.  Logical owners show the deployment where the record was created but doesn't represent if the record is a part of version skew. |
| ENC_CSN | NUMERIC (18,0) | The encounter identifier that the Line/Drain/Airway (LDA) link was documented from. |
