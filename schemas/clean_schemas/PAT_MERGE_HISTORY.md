# PAT_MERGE_HISTORY

**Source:** https://datahandbook.epic.com/ClarityDictionary/Details?tblName=PAT_MERGE_HISTORY

## Description

This table stores the patient merge history. When the system contains two records that actually represent only one patient, the records can be merged together. One record takes on the paitent ID of the other. This table contains the id's that have been merged and therefore are no longer used.
