# ZC_REQ_CONTEXT

**Source:** https://datahandbook.epic.com/ClarityDictionary/Details?tblName=ZC_REQ_CONTEXT

## Description

Care Everywhere Document Request Context records the manner in which a document was requested. Was it manual or automatic? Was it new or updated? Was it via a search or entering a Care Everywhere ID directly?
