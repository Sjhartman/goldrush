# CAREPLAN_TEMP_INFO

**Source:** https://datahandbook.epic.com/ClarityDictionary/Details?tblName=CAREPLAN_TEMP_INFO

## Description

This table contains the basic no-add single items of Care plan template (LCE) records like record name, status, type, display name, etc.

## Metadata

| Property | Value |
| --- | --- |
| Type | Extracted Table |

| Load Frequency | INCREMENTAL |
| Chronicles INI | LCE |
| Release Version | Summer 2009 |
| May contain EHI? | Yes |
