# ZC_ORD_PROC_FREQ

**Source:** https://datahandbook.epic.com/ClarityDictionary/Details?tblName=ZC_ORD_PROC_FREQ

## Description

Procedure frequency category list.  A procedure could be requested for a frequency of 4 per month, for example.  The category values represent the time period portion of this frequency: day, week, month, year.
