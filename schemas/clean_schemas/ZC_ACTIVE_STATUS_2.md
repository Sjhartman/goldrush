# ZC_ACTIVE_STATUS_2

**Source:** https://datahandbook.epic.com/ClarityDictionary/Details?tblName=ZC_ACTIVE_STATUS_2

## Description

This table contains the category information for the provider (SER) record status. This table is different from ZC_ACTIVE_STATUS because ZC_ACTIVE_STATUS_2 refers providers' statuses. ZC_ACTIVE_STATUS refers to statuses for the TRE master file. The two tables are unrelated.
