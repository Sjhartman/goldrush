# ZC_DX_POA

**Source:** https://datahandbook.epic.com/ClarityDictionary/Details?tblName=ZC_DX_POA

## Description

Category table for HAR 611 (also used by HAR 1851).  Contains present on admission (POA) category values.  This category table is used by columns FINAL_DX_POA_C and ECODE_DX_POA_C, which supersede columns DX_POA_YNU and EXT_INJURY_POA_YNU respectively.
