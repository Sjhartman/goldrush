# ZC_PHYSICAL_LOC

**Source:** https://datahandbook.epic.com/ClarityDictionary/Details?tblName=ZC_PHYSICAL_LOC

## Description

This is a category table defining a list of physical locations. Each category value in this table names a specific place, site or area where one or more departments could be located.
