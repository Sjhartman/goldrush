# PROBLEM

**Source:** https://datahandbook.epic.com/ClarityDictionary/Details?tblName=PROBLEM

## Description

This table contains data on care integrator problems associated with a patient.

## Metadata

| Property | Value |
| --- | --- |
| Type | Extracted Table |
| Load Type | REQ |
| Load Frequency | INCREMENTAL |
| Chronicles INI | LPB |
| Release Version | EPIC 2002 |
| May contain EHI? | Yes |

## Columns

| Column | Type | Description |
| --- | --- | --- |
| PROBLEM_ID | VARCHAR (18) | The unique ID for the care integrator problem. |
| TYPE_PROBLEM_ID | VARCHAR (18) | The unique ID for the multidisciplinary diagnosis associated with this problem. |
| CREATED_DATE | DATETIME | The date the problem was added to the patient's care plan. |
| DELETED_DATE | DATETIME | The date the problem was removed from the patient's care plan. |
| DEL_REASON_C | INTEGER |  |
| DISCIPLINE_C | INTEGER |  |
| IP_DISC_TYPE_ID | VARCHAR (18) | The unique ID for the discipline associated with this problem. |
| CM_PHY_OWNER_ID | VARCHAR (25) | ID of the physical deployment owner for this record.  Physical owners will be where the data is hosted, either on the cross-over server or the owner deployment. |
| CM_LOG_OWNER_ID | VARCHAR (25) | ID of the logical deployment owner for this record.  Logical owners show the deployment where the record was created but doesn't represent if the record is a part of version skew. |
| DISPLAY_NAME | VARCHAR (254) | This column shows the record's display name. |
| REC_ARCHIVED_YN | No | Indicates whether the Care Plan Problem record is archived at the record level. |
| PROBLEM_DESCRIPTION_HNO_ID | VARCHAR (254) | The linked note record for the care plan problem description. This column is frequently used to link to the HNO_INFO table. |
| PATIENT_ID | VARCHAR (18) | Links OP care plan problems to the associated patient |
| ALERT_CSN_ID | NUMERIC (18,0) | Stores the CSN of the ALT record associated with the advisory that added this problem. |
| HH_EPISODE_ID | NUMERIC (18,0) | The associated episode ID for a care plan problem. |
| CHILD_LAST_ADDED_DTTM | DATETIME (Local) | The date and time when a goal or intervention was last added to the problem. |
| IS_AUTOGENERATED_YN | VARCHAR (1) |  |
| TREATMENT_DISC_GRP_C | INTEGER |  |
