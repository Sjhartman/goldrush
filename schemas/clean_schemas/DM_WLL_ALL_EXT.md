# DM_WLL_ALL_EXT

**Source:** https://datahandbook.epic.com/ClarityDictionary/Details?tblName=DM_WLL_ALL_EXT

## Description

DM_WLL_ALL_EXT is a data mart table that stores external information related to the general wellness registry metrics for all patients. Only patients that meet the inclusion criteria for the general wellness registry for all patients have information stored in this table. This table stores the data from the latest clarity extract only.
