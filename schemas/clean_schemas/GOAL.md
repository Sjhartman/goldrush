# GOAL

**Source:** https://datahandbook.epic.com/ClarityDictionary/Details?tblName=GOAL

## Description

This table contains data on discrete goals (IGO) records associated with a patient.

## Metadata

| Property | Value |
| --- | --- |
| Type | Extracted Table |
| Load Type | REQ |
| Load Frequency | INCREMENTAL |
| Chronicles INI | IGO |
| Release Version | EPIC 2002 |
| May contain EHI? | Yes |

## Columns

| Column | Type | Description |
| --- | --- | --- |
| GOAL_ID | VARCHAR (18) | The unique ID for the goal record. |
| USER_ID | VARCHAR (18) | The unique ID of the user creating the goal. |
| GOAL_TYPE_ID | VARCHAR (18) | The unique ID of the goal type associated with this goal. |
| PROBLEM_ID | VARCHAR (18) | The unique ID for the problem linked to this goal. |
| CREATED_TIME | DATETIME (Local) | The instant this goal was created. |
| DELETED_YN | VARCHAR (1) |  |
| CM_PHY_OWNER_ID | VARCHAR (25) | ID of the physical deployment owner for this record.  Physical owners will be where the data is hosted, either on the cross-over server or the owner deployment. |
| CM_LOG_OWNER_ID | VARCHAR (25) | ID of the logical deployment owner for this record.  Logical owners show the deployment where the record was created but doesn't represent if the record is a part of version skew. |
| DISPLAY_NAME | VARCHAR (254) | This column holds the display name of this goal. |
| GOAL_DESC_ID | VARCHAR (254) | This column holds the goal description note's ID. |
| EVALUATION_NOTE_ID | VARCHAR (254) | This column holds the evaluation note ID for this goal. |
| GOAL_TEMPLATE_ID | NUMERIC (18,0) | This column stores the goal template used to create this record. |
| GOAL_TEMPLATE_CDR | FLOAT | This column stores contact date real of the goal template contact associated with this goal, stored in Epic's DTE format. |
| ALERT_CSN_ID | NUMERIC (18,0) | Stores the CSN of the ALT record associated with the advisory that added this goal. |
| HH_EPISODE_ID | NUMERIC (18,0) | The associated HH/HSPC episode ID for a care plan goal. |
| EXCL_FROM_SPOC_YN | VARCHAR (1) |  |
| IS_AUTOGENERATED_YN | VARCHAR (1) | Surrogate key used to uniquely identify rows in this (and only this) table on Cogito Cloud only, do not assume the surrogate key in this table will correspond to the surrogate key in another table |
