# ZC_ALT_STATUS

**Source:** https://datahandbook.epic.com/ClarityDictionary/Details?tblName=ZC_ALT_STATUS

## Description

This table holds the alert status categories.  The alert status is a description of what happened to an interaction alert when it was viewed by an end user.  Possible statuses are: overridden, removed, filtered or cancelled.
