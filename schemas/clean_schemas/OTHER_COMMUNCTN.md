# OTHER_COMMUNCTN

**Source:** https://datahandbook.epic.com/ClarityDictionary/Details?tblName=OTHER_COMMUNCTN

## Description

This table stores miscellaneous communication devices that can be used to reach the patient. Examples are mobile phone and pager.

## Columns

| Column | Type | Description |
| --- | --- | --- |
| PAT_ID | VARCHAR (18) | The unique identifier for the patient record. |
| LINE | No | The line number for the information associated with this record. Multiple pieces of information can be associated with this record. |
| CM_PHY_OWNER_ID | VARCHAR (25) | ID of the physical deployment owner for this record.  Physical owners will be where the data is hosted, either on the cross-over server or the owner deployment. |
| CM_LOG_OWNER_ID | VARCHAR (25) | ID of the logical deployment owner for this record.  Logical owners show the deployment where the record was created but doesn't represent if the record is a part of version skew. |
| OTHER_COMMUNIC_C | VARCHAR (66) |  |
| OTHER_COMMUNIC_NUM | VARCHAR (254) | Different kinds of communication numbers such as Home Phone, Work Phone, Fax, Pager, etc, that correspond to the type of device stored in OTHER_COMMUNIC_C. |
| START_DAY_C | INTEGER |  |
| END_DAY_C | INTEGER |  |
| START_TIME | DATETIME (Local) | The beginning time for the time range that this phone number is valid. |
| END_TIME | DATETIME (Local) | The end time for the time range that this phone number is valid. |
| CONTACT_PRIORITY | INTEGER | Priorities are numbers, and are used to set a calling preference for phone numbers.  1 is the highest priority. |
| CONTACT_NOTES | VARCHAR (254) | Notes associated with this phone/contact number. |
