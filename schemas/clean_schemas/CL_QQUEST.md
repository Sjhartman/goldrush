# CL_QQUEST

**Source:** https://datahandbook.epic.com/ClarityDictionary/Details?tblName=CL_QQUEST

## Description

The CL_QQUEST table is the primary table for storing non-contact specific information related to questions in a questionnaire.

## Metadata

| Property | Value |
| --- | --- |
| Type | Extracted Table |
| Load Type | REQ |
| Load Frequency | INCREMENTAL |
| Chronicles INI | LQL |
| Release Version | MU4 - MAY 2001 |
| May contain EHI? | Yes |

## Columns

| Column | Type | Description |
| --- | --- | --- |
| QUEST_ID | VARCHAR (18) | The unique ID of the question record. |
| QUEST_NAME | VARCHAR (254) | The name of the question record. |
| RECORD_STATE | VARCHAR (40) |  |
| QUEST_TYPE_C | INTEGER |  |
| HCF_QUEST_LPP_ID | NUMERIC (18,0) | The programming point that determines if this question is asked. |
| HCF_FILING_LPP_ID | NUMERIC (18,0) | The programming point that files the users response. |
| REG_RESP_INI | VARCHAR (3) | The INI of the master file where the category list item to be used exists. |
| REG_RESP_ITEM | VARCHAR (10) | The item number of the category list item. |
| REG_RESP_TYPE_C | INTEGER |  |
| CM_PHY_OWNER_ID | VARCHAR (25) | ID of the physical deployment owner for this record.  Physical owners will be where the data is hosted, either on the cross-over server or the owner deployment. |
| CM_LOG_OWNER_ID | VARCHAR (25) | ID of the logical deployment owner for this record.  Logical owners show the deployment where the record was created but doesn't represent if the record is a part of version skew. |
| FLO_ID | VARCHAR (18) | This column displays the unique ID of the flowsheet record associated with the question. |
| COPY_FORWARD_YN | VARCHAR (1) |  |
| HPI_ELEMENT_PROMPT | VARCHAR (254) | Configuration for a history of present illness question prompt. |
| HPI_ELEMENT_TYPE_C | INTEGER |  |
| IS_FOLLOWUP_YN | VARCHAR (1) |  |
| CONV_FROM_HX_TEMPLATE_ID | VARCHAR (18) | Used to look up which LQH a given LQL was converted from, if any. |
| PAT_FRIENDLY_QUEST_NAME | VARCHAR (200) | Stores a name for this question that is appropriate for the patient to view. |
| RESULTS_NETWORK_UNIQUE_IDENT | VARCHAR (192) | The unique Orders and Results Network string identifier that was generated by the organization that created this question. |
| PROM_CONCEPT_ID | 40 | Epic-released mapping concept to identify questions used for the same Patient-Reported Outcome Measure across organizations. |
