# ZC_MOD_TYPE

**Source:** https://datahandbook.epic.com/ClarityDictionary/Details?tblName=ZC_MOD_TYPE

## Description

The ZC_MOD_TYPE is a category table which stores the different types of changes that can be done on the OR template for a staff/resource.
