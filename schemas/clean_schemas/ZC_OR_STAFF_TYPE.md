# ZC_OR_STAFF_TYPE

**Source:** https://datahandbook.epic.com/ClarityDictionary/Details?tblName=ZC_OR_STAFF_TYPE

## Description

This table contains the category information for the staff type associated with a staff member on a procedural case. The staff type is defined as a resource type record and then is updated as a category value in the provider record for the staff member.
